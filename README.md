## 快速部署

### 方式 A：纯小白一键部署（强烈推荐，免克隆代码、全自动初始化、秒级运行）

无需克隆代码仓库，无需手动配置复杂的加密密钥。单行命令全自动完成环境检测、密钥初始化、预构建镜像拉取与启动：

#### 🐧 Linux / macOS
在终端中直接执行：
```bash
curl -fsSL https://raw.githubusercontent.com/Xuano47/nofxold/merged/install.sh | bash
```
- **安装位置**：默认安装至 `~/nofxold` 目录。
- **快捷管理**：安装后可随时在安装目录执行 `./nofxold.sh [logs|restart|stop|update|status]`（或直接使用全局命令 `nofxold [命令]`）进行运维。
- **网络与安全**：云服务器（腾讯云/阿里云/AWS等）请在控制台安全组放行 3000 端口。涉及实盘资金安全，**强烈建议配置安全组 IP 白名单**（仅允许您本人的 IP 访问），切勿向全网 (0.0.0.0/0) 裸露！

#### 🪟 Windows (PowerShell)
按快捷键 **Win + R** 输入 **powershell** 按回车打开，直接粘贴执行：
```powershell
irm https://raw.githubusercontent.com/Xuano47/nofxold/merged/install.ps1 | iex
```
> 提示：请认准系统自带的 **PowerShell**，切勿使用传统的 CMD（命令提示符）。
- **前置要求**：请确保电脑已安装并启动 [Docker Desktop](https://www.docker.com/products/docker-desktop/)（左下角显示绿色 Running）。
- **自动化**：全自动在 `%USERPROFILE%\nofxold` 初始化并启动，启动成功后**自动调起浏览器**打开系统界面。
- **快捷管理**：进入 `nofxold` 目录执行 `.\nofxold.bat [logs|restart|stop|update|status]`。

> 💡 **智能兼顾全新安装与平滑升级（再次运行即升级）**：
> - **全新安装**：未安装时执行，全自动初始化安全密钥并拉取运行。
> - **平滑升级**：**只要再次运行上述同一行命令**（或进入目录执行 `./nofxold.sh update` / `.\nofxold.bat update`），脚本会自动识别已部署状态，拉取云端最新构建并无缝重启，同时**自动清理过期历史镜像（`image prune` 释放小鸡 VPS 磁盘空间）**。
> - **数据绝对安全**：升级过程仅刷新镜像容器与管理脚本，`data/data.db` 历史交易数据库与 `.env` 配置 **100% 完整保留，绝无掉库风险**。

```bash
docker compose up -d --build                 # 改代码后本地重新构建
```

## 核心系统架构与特性

### 一、代码级硬核风控（Hard Guardrails）

把命根子交给代码，而不是依赖大模型的“自律”：

1. **交易节流（Trade Throttle）**：
   - **防对冲**：同币种已持仓时绝对拒绝再次开仓。
   - **冷静期**：同向平仓后强制进入 15 分钟冷静期，杜绝追涨杀跌与高频过度交易。
   - **反手放行**：反向开仓无需等待冷静期，保障行情的敏捷捕捉。
   - **锁仓防洗**：持仓不足 15 分钟禁止主动平仓（除非波动击穿入场价的 `≤ -3%` 或 `≥ +8%` 强行放行）。
2. **开仓即带强制止损**：
   - 任何开仓信号必须包含合法止损点位，否则直接拒单。
   - **开仓保护兜底**：若交易所侧挂止损单失败，系统立即自动市价平掉刚开仓位并清理残留挂单，**绝不留下一秒裸仓风险**。
3. **动态追踪止损（移动止损止盈）**：
   - 支持 `update_stop_loss`：只允许上移多单止损、下移空单止损，**只降风险，绝不扩损**。
   - 换单采用先撤旧单再挂新单机制，失败自动兜底恢复，全程保持风控闭环。
4. **价格基准回撤平仓（锁住利润）**：
   - 当浮盈顺向波动达到入场价的 `≥ +5%`，且自最高点回吐利润 `≥ 40%` 时，触发代码级强制止盈平仓。
   - 采用纯价格基准换算，高杠杆下绝不因微小波动被误杀。
5. **统一杠杆与动态名义持仓互锁**：
   - 风控面板提供 1~125X 杠杆平滑滑动条，开仓前代码强制同步交易所杠杆。
   - 单币名义限额与杠杆互锁，根据账户实时总净值动态计算 USDT 限额透传给模型，并在代码层硬核拦截超额下单。

---

### 二、AI 交易认知引擎（Agent Decision Engine）

1. **使用自己的大模型 API（8 槽位平铺）**：
   - 彻底解除官方云端绑定，全面拥抱 OpenAI 兼容规范（POST `/chat/completions`）。
   - 提供 8 个自定义槽位，支持 DeepSeek、OpenAI、Claude、Qwen、本地 Ollama / vLLM 或各类中转服务。
2. **开仓初心锚定（Agent Memory）**：
   - AI 开仓时必须提交一句核心驱动理由（Thesis，≤35字）。
   - **终生固定**：该逻辑伴随持仓生命周期不可篡改，跨轮巡检时注入 Prompt。
   - **轮询动态滚动**：观望或移动止损时动态刷新上轮推演要点，轻量保障长周期持仓的认知连续性，拒绝无谓早抛。
3. **彻底切除人性情绪包袱（零近因偏差）**：
   - 从 Prompt 中彻底移除了历史战绩、近期平仓盈亏统计等情绪干扰源。
   - **纯粹冷血猎手**：AI 每轮面对的仅是客观盘面、实时账户净值与活着的持仓，杜绝止损后的报复性开仓或连亏后的畏缩迟疑。
4. **主备双模型自动容灾（Fallback）**：
   - 交易员支持配置备用模型。主模型超时（慢失败）或端点异常时，毫秒级切换备用模型重试，避免周期决策轮空。
5. **策略全量热重载**：
   - 统一 Markdown 全文编辑器（`SystemPromptEditor`），策略修改保存后秒级生效，无需重启任何容器。
6. **双档 K 线呈现模式（精简模式立省 ~75% Token）**：
   - **破解模型痛点**：大模型看 50~100 行连续 CSV 容易产生注意力稀释（Lost in the Middle），且极速消耗 API 额度并拉高推理延迟。
   - **精简模式（Compact Mode，默认推荐）**：底座依然拉取 30~100 根 K 线用于严谨计算 EMA/RSI/MACD/ATR 等数学指标（数学精度 0 损失）；但对注入 Prompt 的原始 K 线进行**特征工程前置**——提炼出极值区间 `Range (N bars): [Low ~ High]`、波动振幅 `Amp: X.X%`、当前所处客观分位 `Position in Range: XX.X%` 与区间净涨跌 `Net Change: ±X.X%`，表格仅保留最新 5 根微观 K 线。既保留宏观箱体边界，又看清微观影线动能，Token 消耗直降 ~75%。
   - **完整模式（Full Mode）**：策略工作室提供无损切换按钮，自由切回传递 30~100 根全量原始 K 线矩阵，满足长序列推演需求。

---

### 三、微观盘口与订单流分析（Order Flow）

无需接入高昂的高频付费接口，基于币安官方 K 线原生计算：

* **1h 主动买卖净差额（`1h_latest_delta`）**：主动资金进攻烈度与方向直接量化。
* **1h 主动净差额比例（`1h_delta_ratio`）**：跨标的标准化衡量进攻烈度。
* **15m 短周期净差额（`15m_latest_delta`）**。
* **15m 演变趋势（`15m_delta_3bar_trend`）**：3 根 K 线的 Delta 序列，一眼洞察流动性掠夺与筹码吸收反转。

---

### 四、生产可靠性与数据一致性

1. **增量水位同步（币安首推）**：
   - 基于 `trader_fills` 记录账户最后成交时间（水位线）进行增量拉取，停机维护或重启绝不丢单。
   - 由 `PositionBuilder` 统一归因并结算平仓记录与已实现盈亏。
2. **交易员级联隔离**：
   - 交易员创建时拼入 Unix 时间戳生成全局唯一 ID，重建必得全新实例。
   - 删除交易员时级联物理清除其名下所有订单、成交、快照与网格记录。
   - 服务启动自动运行孤儿记录清理机制，维护数据库干净整洁。
3. **云端自动打包（GitHub Actions CI/CD）**：
   - 每次推送到 `merged` 或 `main` 分支，GitHub 云端高配服务器自动触发多阶段编译。
   - 生产服务器无需安装编译工具链，直接秒级拉取 `ghcr.io` 精简镜像。

## 架构概览（数据流）

```
数据源
  ├── 币安公开行情接口 → K 线（直连，主路径）+ premiumIndex（资金费率，1h 缓存）
  └── CoinAnk 免费中转 → K 线兜底（仅限币安未上市标的）
              │
              ▼
        本地原生指标计算
        EMA20/EMA50 · MACD · RSI7/14 · ATR14 · BOLL(20,2)
        主动成交量 · 订单流 Bar Delta (1h+15m 趋势)
              │
              ▼
        双档 K 线呈现（精简模式省 ~75% Token / 完整模式）
              │
              ▼
        AI Prompt 动态注入 → 自定义大模型（主备模型容灾）
              │
              ▼
   代码级交易节流 → 止损校验与开仓保护 → 交易所执行下单
              │
              ▼
   后台增量水位同步 (OrderSync) → 仓位状态归因 (PositionBuilder)
```
